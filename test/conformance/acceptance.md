# Acceptance Coverage

The v1 acceptance suite covers:

- Public API documentation and examples.
- Conservative default configuration.
- Navigation and resource policy decisions.
- Virtual resource resolution.
- Email-style remote resource blocking.
- Unsupported-feature reporting for snapshot, print, and auto-height.
- Windows WebView2 unavailable diagnostics.
- Linux WebKitGTK dependency documentation.
- Explicit exclusion of MIME parsing and HTML sanitization.
