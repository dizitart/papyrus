# Papyrus Documentation

This directory contains architecture, security, platform, migration, and usage
documentation for the Papyrus federated native WebView package.

- [architecture.md](architecture.md): federated architecture and package
	responsibilities.
- [capability_model.md](capability_model.md): generic capability checklist for
	controlled-HTML viewer use cases.
- [email_html_usage.md](email_html_usage.md): guidance for email HTML rendering
	use cases.
- [loading.md](loading.md): content-loading request patterns and behavior.
- [migration.md](migration.md): migration notes for API and behavior changes.
- [platform_matrix.md](platform_matrix.md): platform-by-platform capability
	comparison.
- [quick_start.md](quick_start.md): minimal integration and first-run guide.
- [security.md](security.md): security model and recommended policy defaults.
- [release_workflow.md](release_workflow.md): release process and pub.dev
	publish runbook.
